# The Aspiring Rationalist Ritual Compendium

[View The Published Compendium](https://mwerbos.github.io/rationalist_ritual_compendium/)

## How to Contribute

If you would like to add your ritual or resources here, you can *send me an email* (mwerbos at Google's email service) with whatever materials you have, and I'll put them in.

If you want to make my life easier, however, you can also make a pull request!

* Clone the repo and enter its directory. Run `./setup.sh` to install programs needed to build the repo.

* Add text related to your ritual to the `text/all_rituals.md` file.

* Add new pages as Markdown files to the `text/` directory. 

  * DON'T edit HTML files directly; they are autogenerated from Markdown.

  * To link to your new file `text/new_file.md`, use `[New Link Text](new_file.html)` in Markdown.

  * Feel free to add other filetypes as well (PDFs, images, audio).

* Run `./convert.sh` to convert all files once, -OR- if you would like, run `watch.sh` in a different session while you are editing, and it will automatically convert all Markdown files to HTML whenever they are changed.

* Make sure you add everything to your PR and send it over!
